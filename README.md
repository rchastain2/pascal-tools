# Pascal tools

Small utilities written in Pascal.

## Summary

### Calendar

Calendar in plain text.

### Easter

Date of Easter.

### Easy Colors

Colors by name.

### Hexdump

Hexadecimal view of a file.

### Lowcase

Rename files and folders to low case.

### Screenshot cropper

Remove shadow around screenshots.

### Uploader

Upload files to a website.
